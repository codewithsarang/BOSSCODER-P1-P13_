Learning web development by building practical projects

A practical approach to learning pairs clear fundamentals with small projects. Semantic HTML gives content meaning, while CSS controls presentation and layout.

CSS Grid is useful for two-dimensional layouts because it controls rows and columns together. Here, the lead story spans two columns and rows, while supporting stories occupy named areas beside it.
