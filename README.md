# BOSSCODER – Programming for Web Development I (P1–P13)

This starter submission covers every practical title visible in the supplied assignment sheet.
The sheet contains titles only, not detailed rubrics. Review your instructor's exact requirements before submission.

## Requirements
- macOS
- Visual Studio Code
- Git (install Apple's Command Line Tools if `git --version` is unavailable)
- A browser (Chrome, Safari, or Firefox)

## Folder structure
- `web-practicals/` – working HTML/CSS practicals P5–P13
- `P1-P4-Git-Workflow.md` – terminal, Git, GitHub, README and tag instructions
- `screenshots/` – save your own screenshots here

## Run the website
1. Open this folder in VS Code.
2. Open `web-practicals/index.html`.
3. Right-click the file and choose **Open with Live Server** if you have installed the Live Server extension.
   Alternatively, double-click `index.html` in Finder to open it in your browser.
4. Use the navigation links to inspect P5–P13.
5. Resize the browser or use Developer Tools' device toolbar to test responsiveness.
